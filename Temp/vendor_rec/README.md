 * 实验名称：录音机实验
 * 实验平台：慧勤智远 ESP32-S31 开发板
 * 实验目的：学习驱动ES8389器件

 ***************************************************************************************************
 * 硬件资源及引脚分配
 * 1 LED
    WS2812B   - IO37
 * 2 SD卡(SDMMC驱动)
     CMD  -  IO25
     CLK  -  IO24
     D0   -  IO20
     D1   -  IO21
     D2   -  IO22
     D3   -  IO23
 * 3 ES83889
     ES8389_SCLK    -   IO3
     ES8389_LRCK    -   IO4
     ES8389_SDIN    -   IO5
     ES8389_IIC_SDA -   IO0
     ES8389_IIC_SCL -   IO1   
 * 4 4.3 寸 WKS RGB屏

 ***************************************************************************************************
 * 实验现象
 * 1 程序运行后，会检测分区表中是否存在字库，若不存在则会从SD卡中更新字库到分区表。
 * 2 点击UI界面，实现对应的功能
 * 3 录音与播放都是基于SD卡RECORDER文件夹操作的，如果没有则会自动创建
 
 ***************************************************************************************************
 * 注意事项
 * 1 ESP-IDF默认为FAT格式，若SD卡不是FAT格式，屏幕会显示"SD Card Error!"。
 * 2 如使用exFAT格式的SD卡，在编译前需要将本地安装的IDF中（路径：esp-idf\components\fatfs\src\ffconf.h）
     ffconf.h文件里的 #define FF_FS_EXFAT	0  改为: #define FF_FS_EXFAT  1 来启用exFAT支持。 
     注意：使用完后记得改回0
 * 3 必需要创建的SD卡文件夹在本工程的“SD卡根目录所需文件”压缩包中，将解压出的 SYSTEM 文件夹完整复制到 SD 卡根目录，请提前自行创建。
 * 4 如果注释显示是乱码，点击编码格式，通过编码重新打开选择GB2312编码格式即可
