## 界面 / 动画

### ★ 天气页：日夜天体轨迹动画

**提出**：2026-11-24 01:21（用户原话："太阳或者云或者月亮从早到晚从屏幕左侧移动到右侧"）

**需求**
- 天气页加一个天体元素，**按当前时间从左向右移动**，模拟一天里太阳的位置变化
- 白天显示**太阳**，夜间显示**月亮**，可以叠**云**
- 位置与时间对应：左端 = 清晨（日出），右端 = 傍晚（日落）

**细节待定**
- 轨迹走**直线**还是**弧线**（弧线更像真实日轨，但要算 y 偏移）
- 夜间月亮是固定不动，还是也走一遍轨迹
- 云是静止装饰，还是缓慢飘动（飘动要动，别和天体抢动画预算）
- 颜色是否随时间变（清晨偏暖橙 → 正午高亮白 → 傍晚偏红）

**实现要点（避免踩坑）**
- **只改对象坐标**（`lv_obj_set_x/y`），不要每帧重建图像或改样式
- 天气页 `hold_ms = 20`（50 fps）够用，但**别每帧 lv_obj_invalidate 全屏**
- 位置更新频率不必跟帧率——**每分钟算一次坐标就够**（一天 1440 分钟 ≈ 屏幕宽度 / 1440 px/分钟）
- 注意别和现有天气卡片、温度数字重叠

## 功能

### 时钟页加天气
现在时钟页只有时间和日期。加温度 + 天气图标即可，不必加曲线。

### 无触摸 5 分钟自动进时钟
参考 `prov_watchdog_task` 的定时器写法。进时钟页前要 `backlight_set(0)` 切换时避免闪。

### 每 4 小时壁纸偏移 ±4px（防烧屏）
面板 VCOM 出厂未校准，**大面积固定图案比纯黑更伤屏**。必须配：随机轮换 + 定时偏移 + 遮罩降对比。

### SYSTEM 页加"屏保开关"
写进 `app_cfg`，和背光、VAD 阈值放一起。

## 工程

### 语音对话链路
**v1 已打通（2026-11-24）**：设备说话 → ASR → LLM → TTS → 喇叭回话，端到端 3~4 秒。

后续可优化（按收益排序）：

| 优化 | 收益 | 代价 |
|---|---|---|
| **流式 TTS** | 首字延迟从 1.9 s 降到 0.5 s | 要改 edge-tts 用法 + 设备边收边播 |
| **换爱弥斯音色**（GPT-SoVITS v2） | 音色从通用女声变成角色本人 | 装 v2 整合包 5~8 GB，推理 +1~2 s |
| **真情感**（CosyVoice2 参考音频） | rate/pitch 近似 → 真情绪迁移 | 部署模型，需准备三类参考音频（已有） |
| **多轮上下文** | 现在每轮独立，记不住上一句 | asr_server 加会话历史 |
| **播放中可打断** | 现在播完才能再说话 | 要处理 I2S 抢占 + VAD 恢复 |
| 唤醒词 | 替代手动点 TALK | ESP-SR 加 wake word |

已有素材：`D:\BaiduNetdiskDownload\ai配音模型爱弥斯\`（GPT-SoVITS v2 权重 + 中立/开心/忧伤参考音频）
缺：GPT-SoVITS v2 整合包（未安装，5~8 GB）
