## 界面 / 动画

### ★ 天气页：日夜天体轨迹动画

**提出**：2026-11-24 01:21（用户原话："太阳或者云或者月亮从早到晚从屏幕左侧移动到右侧"）

**需求**
- 天气页加一个天体元素，**按当前时间从左向右移动**，模拟一天里太阳的位置变化
- 白天显示**太阳**，夜间显示**月亮**，可以叠**云**
- 位置与时间对应：左端 = 清晨（日出），右端 = 傍晚（日落）

**细节待定**
- 轨迹走**直线**还是**弧线**（弧线更像真实日轨，但要算 y 偏移）
- 夜间月亮是固定不动，还是也走一遍轨迹
- 云是静止装饰，还是缓慢飘动（飘动要动，别和天体抢动画预算）
- 颜色是否随时间变（清晨偏暖橙 → 正午高亮白 → 傍晚偏红）

**实现要点（避免踩坑）**
- **只改对象坐标**（`lv_obj_set_x/y`），不要每帧重建图像或改样式
- 天气页 `hold_ms = 20`（50 fps）够用，但**别每帧 lv_obj_invalidate 全屏**
- 位置更新频率不必跟帧率——**每分钟算一次坐标就够**（一天 1440 分钟 ≈ 屏幕宽度 / 1440 px/分钟）
- 注意别和现有天气卡片、温度数字重叠

### ★ 桌面常驻角色（Q 版爱弥斯）+ 触摸交互

**提出**：2026-11-25 04:38（看到别人用 ESP32 做的"Q板大肥鱼"，触摸会跑过来抱住手指）

**需求**
- 桌面常驻 Q 版爱弥斯立绘，待机时呼吸/眨眼
- 手指点屏幕 → 她跑到手指位置 → 播"抱住"动作
- 特殊动作：双手拖出文本框（进入语音/文字输入）

**关键：素材只要 5~7 张，不是几十帧**
| 动作 | 帧数 | 实现 |
|---|---|---|
| 待机呼吸 | **1** | 整图上下浮动 2px（`lv_anim`） |
| 跑动 | **1** | 整图平移 + 轻微弹跳 |
| 抱住 | 2~3 | 手臂姿态变了，必须多帧 |
| 拖出文本框 | 3~4 | 手伸出去 |

**技术要点**
- 帧存 JPEG（**已有硬件解码**，几乎零开销），200×200 ≈ 8~15 KB/帧
- 整图用 `lv_img`，位移/缩放/呼吸全走 `lv_anim`，不重建对象
- 一致性：先定 1 张"母版"，后续帧 img2img（重绘 35%）或 ControlNet OpenPose
- 素材来源：本地 SDXL + ControlNet（RTX 5060 Ti 16GB 够）/ 画师 / 改现成素材

**可选（和语音很搭）**：让角色直接表达语音状态
- 待机=发呆 / 录音中=歪头听 / 等回复=转圈 / 她说话=张嘴
- 这样 WS2812 状态灯可以退居次要


### ★ 手机风 UI：桌面 + 播放页 + 歌单

**提出**：2026-11-25 00:55（看到别人用 ESP32-S31 做的桌面/播放/歌单界面，明显是"手机化"的设计）

**需求（三个页面）**

| 页面 | 内容 |
|---|---|
| **桌面** | 全屏壁纸 + 大时钟（时:分:秒）+ 日期 + **圆角渐变图标网格** + 顶部状态栏（时间/电量/WiFi/音乐） |
| **播放页** | 大圆角封面 + **滚动歌词（当前行加粗高亮）** + 进度条 + 上一首/播放/下一首 |
| **歌单** | 封面网格或列表（序号 / 标题 / 歌手 / 时长） |

**"手机感"其实就三样**
```c
lv_obj_set_style_radius(ic, 26, 0);                          // 圆角
lv_obj_set_style_bg_grad_color(ic, lv_color_hex(0xFF9800), 0); // 同色系渐变
lv_obj_set_style_shadow_width(ic, 12, 0);                     // 投影
```

**技术要点**
- 封面：`lv_img` + **硬件 JPEG 解码**（已有能力，几乎零开销）
- 歌词滚动：`lv_anim` 改 y 坐标 + 当前行切样式；**要提前 ~0.3s 滚**，否则看着滞后
- 歌单列表**必须用 LVGL 的复用机制**（`lv_list`），几百条不能一次建 obj
- 图标素材：建议**字体图标**（一个 ttf 带几百个，可调大小颜色）

**可复用**：现有 `APPS` 九宫格改造，不是从零写

**工作量**：桌面 1~2 天 / 播放页 2~3 天 / 歌单 1 天

**和 #7 在线音乐的关系**：这条是**界面**，在线音乐是**数据源**。UI 可以先做（用 SD 卡的本地歌曲），接在线播放是后一步。

## 功能

### 时钟页加天气
现在时钟页只有时间和日期。加温度 + 天气图标即可，不必加曲线。

### 无触摸 5 分钟自动进时钟
参考 `prov_watchdog_task` 的定时器写法。进时钟页前要 `backlight_set(0)` 切换时避免闪。

### 每 4 小时壁纸偏移 ±4px（防烧屏）
面板 VCOM 出厂未校准，**大面积固定图案比纯黑更伤屏**。必须配：随机轮换 + 定时偏移 + 遮罩降对比。

### SYSTEM 页加"屏保开关"
写进 `app_cfg`，和背光、VAD 阈值放一起。

### 在线音乐（网易云 / QQ 音乐）

**参考**：`xiaozhi-esp32-qq-music`（GitHub）—— 架构是"解密/取流放服务端，ESP32 只拉流+解码"

**要点**
- **走 PC 代理**（扩展现有 `asr_server.py`），设备端完全不碰 HTTPS/cookies
- 设备端要 **MP3 解码**（helix / libmad / esp-audio-libs）
- UI 复用现有音频页 + 封面（硬件 JPEG 解码）+ 滚动歌词

**先做最小闭环**：语音说"放首歌" → 代理返回 MP3 流 → 设备解码播放

**难点**：API 反爬（cookies 时效）、HTTPS 证书、MP3 流式缓冲

### 双核占用统计

`cpu_stats_task` 已写好但用 `#if 0` 关着（`components/voice/src/voice.c`）。需要：
1. sdkconfig 开 `CONFIG_FREERTOS_GENERATE_RUN_TIME_STATS=y` 和 `CONFIG_FREERTOS_RUN_TIME_STATS_USING_ESP_TIMER=y`
2. 去掉两处 `#if 0`

⚠️ 改 sdkconfig 会触发**全量重编译**（十几分钟），单独安排一次，别和别的改动混。
`IDLE0`/`IDLE1` 的占比反推每核占用（`核占用 = 100% − IDLE占比`）。
